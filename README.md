# Comisión de Gestión de Talento Humano de las Altas Montañas
Es una API Rest Full para la gestión de usuarios, eventos, organizaciones, convenios, ofertas laborales, etc.

## Tecnologías
- Node.js
- Express.js
- PostgreSQL
- Swagger (OpenAPI)
- Jest

## Instalación rápida

```bash
git clone <url-del-repositorio>
cd backend
npm install
```

## Creación de un archivo `.env`
Debe seguir el formato del archivo de ejemplo `.env-example`

- Ejecutar el proyecto
```bash 
npm run dev
```

API disponible en:
`http://localhost:300/path`

Swagger disponible en:
`http://localhost:3001/api-docs`
